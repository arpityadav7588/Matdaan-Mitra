🚀 Excited to share my latest project: Matdaan Mitra (मदान मित्र)!

For the PromptWars Virtual hackathon, I built an AI-powered election literacy assistant designed to empower 1.4 billion Indian citizens.

Key Highlights:
✅ Animated Election Timeline using @chenglou/pretext for zero-reflow rendering.
✅ Multilingual AI Chat (Hindi, Tamil, Telugu, English) powered by Google Gemini.
✅ Privacy-First Eligibility Checker using SHA-256 client-side hashing.
✅ Voice Mode for accessible, hands-free information.

Built using a multi-agent orchestration pattern to ensure top-tier UI/UX, security, and AI performance.

Democracy is at its strongest when voters are informed. Check out the demo! 🗳️
